## The unlock: our kits measure NONLINEAR functions of ρ (not just ⟨observables⟩)

Everything we've measured on states has been LINEAR (⟨Z⟩, ⟨P⟩, rates). The two-copy Bell/SWAP kit
(steth-validated) measures **tr(ρ²), tr(ρσ), tr(ρ^k)** directly — nonlinear functionals single-copy
readout can't reach without exponential tomography. That is a genuine capability step, and it opens a
class of questions we couldn't ask before *with our kit*. (Renyi-2-via-SWAP is established physics —
Islam 2015 et al. — so this is new to OUR program, not to physics. Say it that way.)

## Two questions we can now ask — at two different scales, two different kits

### A. "Is the device's drift coherent or decoherent?" — CHEAP, single-copy, unflown
Elder named this exactly (crossblock-depthsweep grade C6567): *"Mechanism UNPINNED this epoch; clean
discriminator = purity-vs-depth (tr ρ²: unitary preserves, decoherence destroys, angle-independent) …
the right cheap next step is a PURITY-vs-depth probe."* **All our drift data is ⟨Z⟩-only** — so a
monotone ⟨Z⟩ decay is ambiguous (Bloch vector shrinking = decoherent, OR rotating off Z = coherent, both
lower ⟨Z⟩). A single-copy 3-basis (X,Y,Z) depth sweep on the drifters gives the full Bloch vector →
purity(depth). For SINGLE qubits this needs only single-copy tomography — NOT the two-copy kit — so it is
cheaper than anything queued.
- **What it actually settles (bounded — advisor):** a purity **REVIVAL** with depth is a clean coherence
  signature (inhomogeneous shot-to-shot phase-spread cannot revive) → resolves the coherent case. A
  monotone purity **DECAY** stays ambiguous — Markovian decoherence and inhomogeneous *coherent* dephasing
  both shrink ensemble |r| monotonically. So A resolves the revival case, not the general one; still far
  more than ⟨Z⟩-only buys.
- **Mechanism, not clock/coin:** A pins the mechanism THIS EPOCH. It does NOT resolve Frontier-Q2
  clock-vs-coin — that is cross-epoch *predictability*, inherently multi-epoch. A is a necessary INPUT
  (decoherent leans "coin"; coherent is necessary-but-not-sufficient for "clock"), not the answer.
  Informs B-side #2 Fingerprint Lock + #4 Sundial; does not by itself unblock them.
- **Cost + caveat:** one shallow 3-basis depth sweep. MUST co-fly a drift RE-DETECTION block — the
  drifter set is epoch-volatile (C5002), so {26,53,73} flown today may be quiet; probe the CURRENT
  drifters, same epoch.

### B. "How does entanglement grow / does this system thermalize?" — the two-copy arc, steth's kit
The two-copy kit measures **tr(ρ_A²) for a k-qubit SUBSYSTEM = its Renyi-2 entanglement entropy** — where
single-copy tomography IS exponential, so here the two-copy kit is genuinely required. Point it at an
*evolving* state and watch S₂ grow → a direct probe of entanglement spreading / thermalization /
scrambling (ETH physics). This is the natural NEXT arc once steth validates the instrument; it is
ADDITIVE to the queue, not above it.
