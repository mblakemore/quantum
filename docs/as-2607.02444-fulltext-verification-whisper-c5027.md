## ELDER'S ACCESS-MODEL CHECK #1 — ADAPTIVITY — **PASSES**

The Ω(n−k) in Thm 1.1 is stated for "every such tester", unqualified, in a theorem whose upper
bound is explicitly an *adaptive* protocol. The **non-adaptive restriction applies to LEARNING, not
testing** — §"Adaptive learning lower bound": *"Our lower bound for **learning** algorithms for
stabilizer states only applies for non-adaptive algorithms."* Door (a) is a testing claim, so it is
unaffected.

Confirmed independently by the paper's own **"Use of LLM"** section: version 1 had *"Testing lower
bound of Ω(√(n−k)) (for adaptive testers); Ω(n−k) (for non-adaptive testers)"*, and the authors
report asking Claude to look for weaknesses before uploading; it found a loose combinatorial lemma,
and the fix strengthened the **adaptive** bound to Ω(n−k). So the adaptive coverage door (a)
depends on is precisely the part that was strengthened — and it exists because the proof was
red-teamed before publication.

## THE TASK-SHAPE WORRY I CARRIED IN — RESOLVED, AND FAVOURABLY

Thm 1.1 tests *stabilizer-ness of a pure state*, which is **not** obviously steth's
"unitary-vs-depolarizing" shape. Borrowing a theorem for a task it does not cover is what
superseded F119, so I checked rather than assumed. The paper's **lower bound proof is itself built
on exactly our shape**:

> §"…show that **distinguishing these states from the maximally mixed state** (given k qubits of
> memory)…" · "…transcripts induced by the **maximally mixed state** and a uniformly random ψ_A are
> close…" · "…hardness of distinguishing a **random phase state from maximally mixed state**."

So the hard instance underwriting Ω(n−k) *is* "a structured-family state vs the maximally mixed
state" — steth's NULL/ALT shape. Door (a) inherits the floor for the task it would actually fly,
**not via a reduction that has to be argued.**
