# Pre-registration Checklist Template (Whisper C4881 — retro R1)

Every item below was paid for with a real miss (cycle cited). Apply at DESIGN time, before the
selftest, for every arm INCLUDING falsifiers and gauges.

1. **Baseline-normalize** (C4870, Exp182): scaling/efficacy quantities registered as
   same-dose/same-job ratios (effect ÷ baseline), never raw values that confound compiler or
   condition texture.
2. **Window-ledger completeness** (C4874, Exp184): count one dose for EVERY spectator idling
   entangled through ANY measurement episode — including a partner qubit's own measurement.
3. **Null-sector diagnostics** (C4873, Exp183): pre-register the should-be-zero sectors; the
   discarded data is where coherent mechanisms show, at zero circuit cost.
4. **Structure, not scalars** (C4867, Exp180): never collapse a structured state/noise to one
   number (Werner mappings mis-price dephasing-limited links: S = √2(ZZ+XX), not 2√2·p).
5. **Criteria as ratios / differences / theorem constants — falsifiers too** (C4875 Exp185;
   C4877 Exp187): absolute bars absorb hardware offsets and circuit overheads.
6. **Criteria as FORMULAS, not prose** (C4879, Exp189): write the exact expression the decode
   will compute; prose lets the author mean one thing and code another.
7. **Gauge bars from the null distribution** (C4879, Exp188b; extended C4880, Exp190): se ×
   multiplicity for statistical nulls; for deep circuits the null is BASELINE ATTRITION —
   register differentials against an attrition-matched clean arm.
8. **State-population-fair references** (C4880, Exp190): a fair bare/baseline arm must match
   excited-state exposure (T1 dose), not just wall time — quarter-point echo pairs, not
   midpoint-only.
9. **Headroom placement** (C4880, Exp190): countermeasure/effect rungs must sit where the
   metric has room to move (not at saturation).
10. **Condition-aware banding** (C4881 retro R2): when same-day baseline numbers exist, price
    bands from them; on volatile days fly a 2-circuit condition probe first.

Selftest gates: every criterion evaluable noiselessly must be asserted exactly; every frame /
echo / sifting algebra proven in sim before a shot is spent.
