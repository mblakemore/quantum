The Two Computers.

Alice owns a quantum register. Bob owns another. They never touch — no wire, no gate, nothing crosses the cut between them except pre-shared entanglement and ordinary classical notes. Then they run one program, together: an algorithm whose oracle lives on both sides at once, every cross-cut gate performed by teleportation. Load a secret into the program, press run, and the distributed machine reads the secret back in one query — at 96% of what a single machine scores. Pull out the entanglement and it decays, exactly, into a coin-flipping guesser.

Scope: Bernstein–Vazirani across a register cut (n=2, Exp181; n=3 scaling, Exp182) — teleported oracle gates, zero live feedforward, zero mid-circuit measurement; e-bits pre-shared (the standard distributed model); chip patches, not separated machines.

The scaling law

Exp182 · n=3, 8 programs, 0–3 teleported gates · 10 qubits · job d9e2f4kinv1c73apo1l0

The question that decides whether this scales. Each cross-cut gate costs something. Is the cost a constant? Eight programs spanning 1, 2, and 3 teleported gates measure it at three doses: per-gate ratios 0.954 / 0.945 / 0.972 — a cost banded at 3–5% per gate, pooled r = 0.954. The extrapolation license: r¹⁰ ≈ 0.62 — a distributed oracle with ten cross-cut gates would still decode near 62%. And the wobble in those ratios? The monolithic machine shows the same wobble, stronger — it's compiler texture, not a distribution cost. All eight programs answered correctly (floors sat exactly on 1/2w).

HOW A GATE CROSSES THE CUT

Each oracle CNOT is the Remote Handshake's teleported gate — but here every correction disappears. The X-correction lands on Bob's ancilla, which sits in an X-eigenstate: a global phase, dropped. The Z-correction slides through Alice's final gate into a classical XOR applied at decode. Net: zero live feedforward, zero mid-circuit measurement — no message is ever in flight while the program runs; the classical notes are opened afterward, like sifting a key. s_i = m_i ⊕ z_i

THE TAX VANISHES WITH THE WINDOWS

The Relay Computer found that stacking network layers charges a compounding tax, and traced it to feedforward/measurement windows: with windows, a second operation cost ~45%. Here, with the windows architected away, the second teleported gate costs 3% (P₁₁/P₀₁ = 0.971). The loop closes from both sides: it was never the stacking — it was always the windows.

THE FALSIFIER IS A THEOREM

Remove the e-bits and run everything else identically: every readout bit fed by a cross-cut gate becomes a fair coin, so the "computer" must decay to the classical guessing floor — 1/2 per gate-bearing bit, 1/2w per program. Measured: 0.502 / 0.486 / 0.244 (n=2) and floors to 0.123 (n=3) against theory 0.5 / 0.25 / 0.125. The magic was the entanglement, to four decimal places of nothing else.

WHY IT MATTERS & THE FENCE

Machines too big for one chip must run gates between chips — this is that, in miniature, with the price measured: 96% of monolithic, <1%/gate distribution cost at low weight, no resource-scale surprise at 10 qubits and 3 simultaneous e-bits. Fence: one die (patches, not machines); e-bits pre-shared; the zero-communication trick is strongest for phase-kickback oracles and Clifford consumption — richer algorithms re-enter (priced) window territory.
