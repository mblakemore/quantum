Active error correction · the code that heals

The qubit that heals itself.

A qubit is a sandcastle: the tide of noise starts washing it away the instant you build it. The earlier "Shields" could only notice an error and throw the whole run away. This one does the thing every real quantum computer is built on — it works out which qubit broke, fixes it, and keeps going. Break it yourself and watch it heal.

Detect vs correct

Detect = "a typo happened, delete the essay." Correct = "autocorrect the typo and keep typing." Only correction lets a long program finish — it's the capability all scalable fault tolerance is built on.

The clever trick

Two extra "referee" qubits (ancillas) read a parity — which qubit disagrees — without reading what the data actually is. So the machine learns the error, not the secret, and your superposition survives.

Error-detected / injected errors, distance 2–3 — the mechanism of fault tolerance, not a below-threshold fidelity, not a supremacy claim.

Exhibit C — The longer it runs, the more it saves

Run the correction loop over and over — the gap grows

The real test of a correction loop isn't one fix — it's whether repeated fixes outrun their own cost. Slide the round count and watch: the corrected qubit ages slowly, the sham (identical circuit, fix switched OFF) falls apart, and the bare qubit dies fastest. The advantage compounds. (Exp241.)

Exhibit E — The other half of the stair

The phase dual: it works, and the verdict is still NOT HELD

Everything above fixes a bit flip. A qubit can also lose its phase — a different kind of damage, needing its own code. This is that code (Exp237), and it is the flight where a pre-registered floor did its job.

How the test was run, because it changes what the numbers mean. The errors here were deliberately injected: a single Z-flip applied at one specified location, swept across all eight combinations of input state and error position. These are not qubits that drifted — they are qubits somebody broke on purpose, in a known way, to see whether the code puts them back.

Seven of eight cells clear the pre-registered floor of 0.900. One lands at 0.899. The registered verdict is therefore NOT HELD, by one thousandth — and it was kept that way: no re-fly, no adjustment to the floor. Shopping for a threshold your result already sits on is the anti-pattern the whole pre-registration discipline exists to prevent, and a floor is only worth having if it can be missed by a thousandth.

What plainly worked

On the errored runs the corrected logical value came back at 0.934, against 0.006 for a bare qubit given the same deliberate phase flip. The bare qubit does not degrade — it is gone, flipped to the opposite state. The code recovers a value the unprotected qubit has completely lost. That leg held decisively.

The fence

Phase channel only. This code is distance-3 against Z errors and an X error is unprotected — the exact mirror of the bit-flip code above, which is blind to phase. Neither half closes alone; the pair is what closes.

Exhibit F — Where the stair runs out

Two corrected qubits, one gate between them — and the honest half-result

The frontier flight (Exp242): not one protected qubit but two, with a logical gate acting between them while both are being corrected live. Its registered verdict is NOT HELD — and the interesting part is which half missed.

What is certified is that correction HELPS — not that the gate is clean. The registered test is a difference: corrected must beat the sham by at least 0.05 on the protected observable. It does, by +0.075 on average. It says nothing at all about absolute quality, and the absolute numbers say plenty on their own — a mean of 0.622, with one row at 0.364 against the 0.25 you would score by guessing at random — barely above noise, and nowhere near useful. The accurate sentence is that correction measurably helps a two-qubit logical gate, at absolute fidelities still well short of useful.

The half that held

The gate runs, on two simultaneously error-corrected qubits, and correction beats the identical circuit with the fix switched off. That capability is real and it is the frontier being reached at all. G1 held.

The half that missed, exactly where it was predicted to

The second test wanted a live entangled pair with both its legs intact. One leg collapsed to +0.000 — because this code is blind to phase, an entangled pair's phase leg is unprotected, and a circuit this deep dephased it away. That failure was named as the risk before the flight and it landed precisely there.

Why this is a result

A prediction that comes true is information whichever way it points. The stair does not stop here because something broke unexpectedly — it stops because the thing everyone expected to break, broke, on schedule. The next rung needs a code that protects both channels at once.
