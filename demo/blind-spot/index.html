The Blind Spot.

A decoder that grades its own answer with a self-consistency check can be driven, by the right coherent noise, to rank a wrong answer above the true one. It doesn't fail loudly — it hands you a confident lie. The only thing that catches it is a separate ground-truth channel. The lie lives where the check, by construction, cannot look.

Scope: narrow — coherent, signal-channel noise. Under generic noise the check is fine (recovers to depth 407). Toy scale. Not "decoders lie in general."

2 · It's a blind spot, not a general failure

The control (ibm_kingston): same noise, same qubits, different location — does the lie survive?

If deep circuits simply lied, the failure would appear wherever noise is added. It does not. Put the same amount of noise on the oracle's own signal channel (copy) vs on spectator qubits (generic): only the signal-channel version inverts. Generic noise degrades gracefully and still recovers at depth 407. The lie needs noise aimed at the exact channel carrying the answer.
copy = noise on the signal channel (inverts → lies) generic = noise elsewhere (recovers at depth 407)

3 · The same blind spot, in error correction

A distance-3 repetition code on ibm_fez · the syndrome check is the self-check

Error correction has its own self-check: syndromes, which flag when neighbouring qubits disagree. It catches an ordinary bit-flip. But a logical error — the one that actually changes your stored answer — flips every qubit together, leaves every syndrome reading "all clear," and slips past unseen. Same blind spot: the failure lives in the check's null space (H·z = 0, verified d=3/5/7).

The court

A self-consistency check certifies against inconsistent errors — noise that breaks the check. It is blind to a coherent failure that lives in its null space (the QEC logical error: equal consistency, syndrome silent) or that the noise favours (the Simon inversion: the wrong answer scores higher). Ground truth — a planted secret, a known input — is a separate channel, and the only one that survives both.
