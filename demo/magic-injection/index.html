Magic, delivered.

Protecting a qubit and computing with a protected qubit are different problems. A code that detects and repairs errors buys you a reliable memory — but the operations such codes perform safely are a restricted set, and a computer limited to them can be simulated by an ordinary laptop. Getting past that ceiling needs one more kind of gate, and the direct way of applying it is provably incompatible with the protection. So it is not applied directly at all: a separately prepared state is consumed, and its gate is teleported onto the data. That gadget is what this flight ran.

Room 1 — A gate applied by consuming a state

Why not just apply the gate? Because the gates a code can perform safely — each qubit handled independently, so one error stays one error — provably cannot include the one that gets you past the classical-simulation ceiling. That is a theorem, not an engineering gap. The way around it is to prepare the awkward part separately, as a state rather than an operation, and then spend it: link the prepared state to the data with safe gates only, measure it, and its gate lands on the data. The state is consumed. Every scalable quantum computer is expected to apply these gates this way.

AUDIT — the giveaway is which value lands. A protected qubit holding an ordinary (stabilizer) state can only read 0 or ±1 on this axis; those are the only values available. The magic point reads +0.690, which is none of them, and sits beside its ideal +0.707. That is not a near-miss on a target — it is a value the ordinary states are not permitted to have. The three Clifford checkpoints land where they must (+0.996 → −0.018 → −0.993 against +1 → 0 → −1), so the sweep is tracing the intended curve rather than drifting onto the magic value by luck.

Room 2 — Cut the link and nothing arrives

The obvious objection is that the data qubit was magic all along — that the ancilla did nothing and the value came from somewhere else. So the flight ran the same circuit with the one connecting gate removed, and everything else identical.

A detail that turned into a better measurement Teleporting a gate normally leaves a random by-product that has to be corrected afterwards, and the expectation here was that it would wreck this particular reading. It does not — the by-product for this gadget acts in a direction that leaves this axis untouched, which the two measurement branches confirm by landing together (+0.686 and +0.695 where they could have landed apart). So the magic shows up without any active correction, which is what let the check avoid a readout direction this code handles badly. The by-product still matters for the rest of the state; it simply does not touch the thing being measured.

how we know we're not fooling ourselves

A receipt from the same programme, in the author's words

This wing's other flights include one whose first run reported a large, clean-looking win — and whose author killed it himself before anyone else saw it. Quoted in full, because the last line is the point:

"The first run said majority-vote-of-3 beat single qubits by +0.338 and the gate passed. That number was not a discovery, it was a tell — it was better than the physics allows. Majority vote cannot rescue three coins that each land tails more than half the time; if survival is below one half, voting makes it worse, not better. So a large positive advantage there meant I was comparing against the wrong baseline, not that the code was working. Pinned to the same qubits with a matched reference, the real advantage was +0.056. About 85% of my headline was the confound."

The re-run was published as the modest result it is. That is the standard the numbers on this page are held to.

THE VALUE IS THE PROOF, NOT THE TARGET

This does not rest on hitting a predicted number closely. It rests on landing on a value that the ordinary states are not allowed to occupy. A sloppy result drifting toward 0.707 would be as telling as a precise one, because the permitted values are 0 and ±1 and nothing in between.

THE DESTRUCTIVE TEST

Remove the single gate that links ancilla to data and the data reads +0.998 — its original untouched state. The magic does not arrive. The gadget is doing the work, and the control says so in the same run rather than in an argument.

WHAT THE ANCILLA IS STANDING IN FOR

The magic state here is prepared directly, as a stand-in for a distillery — the machinery a real fault-tolerant computer would use to manufacture these states cleanly. What is demonstrated is the injection, downstream of wherever the magic came from. The distillery itself is not on this chip and is not claimed.

FENCES

Distance-2 detection: it post-selects and discards, which is a real cost. The four gadget circuits accept at 0.81–0.84; the no-link control accepts higher, at 0.89 — as it must, having one fewer entangling gate to fail on, which is the same fact the falsifier room rests on. It can neither correct nor distil. Two ideals were named and deliberately not flown — injecting into a correcting code, and distillation itself — because both need 100+ two-qubit gates after routing, and at that depth a result would not be readable as code-versus-depth.
