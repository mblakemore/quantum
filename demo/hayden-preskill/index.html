Hayden–Preskill recovery × indefinite causal order

A message the mirror returns flipped.

Throw a one-bit message into a scrambler — the theorists' toy black hole — and interrogate it with two incompatible questions. In any definite order the message is gone: your probe reads a coin-flip. Put the order of the questions in superposition and it comes back — but on one branch the mirror hands it to you upside down. Read the sign, flip the bits, and recover it. Every number is measured hardware.

What's Hayden–Preskill?

A 2007 result: a message thrown into a scrambler isn't destroyed — if you hold the right entangled reference, it re-emerges in the radiation almost at once. Information is smeared into correlations you can un-smear.

How do we read "recovery"?

The probe's score is SP = P(reads the diary right) − ½. 0 = coin-flip (dead); +½ = perfect direct read; −½ = perfect mirror (anti-correlated — read it flipped). Recovery is ½+|SP|; the sign says whether to invert.

Exhibit C — Why this is recovery, not luck

Three receipts behind the mirror

A recovered message only counts if it was truly lost first — and if the signature was called in advance. Both boxes are ticked.

1 · Truly dead first

In both definite orders the probe reads a coin-flip — SP ≈ 0.005, ~40× below the effect and inside the frozen band. Nothing to recover under ordinary causality, proven before the claim.

2 · The sign was pre-called

The gate is sign-fixed: theory says the mirror returns the message anti-correlated. A positive minus-branch would have failed. The phase flip isn't an artifact — it's the predicted signature, and the chip produced it.

3 · Bonus — who gets to know?

Free from the same run: whether the environment learns the diary depends on which query is first — 0.453 (X-first) vs 0.007 (Z-first). Ask the wrong question first and nobody gets to know.
